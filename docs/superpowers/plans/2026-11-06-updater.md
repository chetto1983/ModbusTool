# Piano — aggiornamento automatico

**Goal:** l'app trova, propone e installa le nuove versioni, solo con il consenso dell'utente.

**Architecture:** `tauri-plugin-updater` + `tauri-plugin-process`; `src/lib/updates.svelte.ts`
(stato, controlli, installazione); `UpdatesDialog.svelte` (consenso, offerta, impostazioni);
job `publish` della release: firma e `latest.json`.

**Tech Stack:** Tauri 2 updater 2.14.1, process 2.4.0, Svelte 5, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-11-06-updater-design.md`

**Global Constraints:** gate di `CLAUDE.md`; nessuna chiave privata nella sessione o nel repo;
privacy del README vera.

**Review Focus:** firma dopo SignPath; nessun contatto di rete senza consenso; lavoro Modbus
fermato prima dell'installazione.

**Decisions taken while writing this plan:**
- `createUpdaterArtifacts` spento: la firma dell'updater avviene solo nel job `publish`.
- Esc sul modal di consenso equivale a "No" (scelta modificabile in *Updates*).
