A master and a slave in one window, for TCP, UDP, RTU, ASCII and RTU over TCP. Every data type and byte order, a frame-by-frame traffic monitor, and dashboards with trends, gauges and command panels.

Everything for the commissioning bench

Master

Several polls at once, each with its unit, function, range and interval. FC01–FC06, FC15, FC16, with per-poll statistics. Edit a value in the grid to write it.

Slave

Several unit ids with full tables, response delay, broadcast writes, and generators: sine, ramp, random and square wave. CSV import and export.

Data types

UInt16 to UInt64, Int16 to Int64, Float32, Float64, hex, binary and ASCII, in the byte orders ABCD, CDAB, BADC and DCBA. Labels per register.

Traffic monitor

Every frame, decoded into words you can read, with filters and CSV export. See exactly what went on the wire and what came back.

Dashboards

Trends with zoom, values and gauges with alarm colours, bars, lamps, buttons, switches, selectors and setpoints. Arrange them by dragging.

Scaling like SCADA tags

Map raw counts to engineering units, for example 0…27648 to 0…100 %. Setpoints are typed in their own units and written raw.

Register maps

Import a device's register table from CSV: names, types, units and scaling become a dashboard table that reads them all. Export it back for the next device.

Recording to file

Record a dashboard to CSV, one file a day and one column per value, ready for a spreadsheet. It keeps recording with the window in the background.
